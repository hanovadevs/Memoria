# Memoria | Premium Digital Products Platform

Memoria is a high-end, cinematic digital storefront built with Next.js 15, TypeScript, and Framer Motion. It is designed for brands that value minimalism, elegance, and performance.

## 🚀 Tech Stack

- **Frontend**: Next.js 15 (App Router), TypeScript, Tailwind CSS
- **Animations**: Framer Motion
- **Backend**: Next.js API Routes
- **Database**: MongoDB Atlas with Mongoose
- **Icons**: Lucide React

## 📁 Project Structure

- `/src/app`: Application routes and pages
- `/src/components`: Reusable UI, layout, and section components
- `/src/lib`: Utility functions and database connection
- `/src/models`: Mongoose database schemas
- `/src/store`: State management (Zustand structure ready)

## 🛠️ Getting Started

1. **Clone the repository**
2. **Install dependencies**: `npm install`
3. **Setup environment variables**: Copy `.env.example` to `.env.local` and add your keys.
4. **Run the development server**: `npm run dev`

## ✨ Features

- **Premium UI**: Light-themed, grayscale palette with glassmorphism and high whitespace.
- **Cinematic Animations**: Fade-ups, staggered reveals, and smooth hover effects.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop.
- **Full-Stack Architecture**: Ready for MongoDB integration and product management.
- **Admin & Dashboard**: Dedicated interfaces for users and administrators.
